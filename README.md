# Spring Boot React Authentication

A full-stack authentication and authorization application built using React.js and Spring Boot. The project demonstrates user registration, login, password encryption, and role-based authorization using Spring Security.

## 🚀 Features

- User registration
- User login
- Password encryption using BCrypt
- Spring Security authentication
- Role-based authorization
- User, Admin, and Guest roles
- Protected API endpoints
- React login and registration forms
- React Router navigation
- Login/logout functionality
- REST API integration
- Responsive Bootstrap UI

## 🛠️ Technologies Used

### Frontend

- React.js
- JavaScript
- React Router
- Axios
- Bootstrap
- HTML5
- CSS3

### Backend

- Java
- Spring Boot

- Spring Data JPA
